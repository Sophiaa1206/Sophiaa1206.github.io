## 终于上线了！

这是我的第一篇博客文章，也是这个博客的起点。

作为一个正在学习成为 AI 产品经理的人，我一直想拥有一个属于自己的博客空间来记录学习笔记、技术分享和产品思考。今天，这个愿望终于实现了。

## 技术栈

这个博客使用的技术栈非常轻量：

| 技术 | 用途 | 说明 |
|------|------|------|
| [Hugo](https://gohugo.io/) | 静态站点生成器 | 构建速度极快，Go 语言编写 |
| [PaperMod](https://github.com/adityatelange/hugo-PaperMod) | 主题 | 简洁优雅，功能丰富 |
| [GitHub Pages](https://pages.github.com/) | 托管 | 免费，自动部署 |
| [Giscus](https://giscus.app/) | 评论系统 | 基于 GitHub Discussions |

## 为什么选择 Hugo + PaperMod

1. **速度快** — Hugo 是目前最快的静态站点生成器之一，构建整个网站只需毫秒级
2. **主题优雅** — PaperMod 设计简洁现代，支持暗色模式、搜索、标签等常用功能
3. **零成本** — GitHub Pages 提供免费托管，还有自定义域名支持
4. **版本控制** — 所有内容都在 Git 仓库中，随时可以回溯
