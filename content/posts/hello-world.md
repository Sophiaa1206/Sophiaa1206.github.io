这是我在这个博客上发布的第一篇文章。

### 为什么要写博客？

写博客是一个很好的习惯，它可以帮助我们：

1. **整理思路** — 写作的过程就是梳理思维的过程
2. **记录成长** — 回头看自己写过的文章，能清晰地看到自己的进步轨迹
3. **分享知识** — 你的经验可能正是别人需要的
4. **建立连接** — 通过文章认识志同道合的朋友

### 代码示例

```python
def greet(name):
    """一个简单的问候函数"""
    return f"Hello, {name}!"

print(greet("World"))
```
